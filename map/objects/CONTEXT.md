# Object shelf

## Job

This shelf defines the durable nouns an editor encounters. Cards group representations by product meaning rather than mirroring the source tree.

## Inputs

- Canonical client shapes: `lib/types.ts`.
- Persisted representations inferred from Supabase calls in `app/api/` and `context/`.
- Browser-persisted representations in client contexts and admin pages.

## Process

Open `_index.md`, select one noun, then open only that card. Follow its `See` citation before changing source. Use schema cards for cross-representation details and process cards for movement.

## Output

Each verified card states one meaning, its representations, first-order connections, and a bounded change waterfall.

## Human check

Verify that the card distinguishes live sources that share a name. If a new representation appears, update the existing noun card instead of creating a duplicate noun.
